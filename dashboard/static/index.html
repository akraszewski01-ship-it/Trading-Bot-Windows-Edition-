Paper vs Live

The bot runs in PAPER mode by default — no real money is used. To go live:

  1. Save your credentials above (Ready shows YES)
  2. Watch the bot run in paper mode for at least 15 minutes
  3. Edit the .env file and change TRADING_MODE=paper to TRADING_MODE=live
  4. Click Stop, then Start to apply the new mode
