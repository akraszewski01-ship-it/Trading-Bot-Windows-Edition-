About this system

Kalshi Trading Bot - a production-grade automated trading system for Kalshi's 15-minute crypto markets.

The system runs in PAPER mode by default (no real money). To trade live:

  • Enter your Kalshi API Key above and save it
  • Verify the bot works in paper mode for 15-30 minutes
  • Edit .env and change TRADING_MODE from "paper" to "live"
  • Restart the bot
